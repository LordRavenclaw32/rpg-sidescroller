# Ecos de Valdoria

Jogo de ação 2D side-scroller com elementos de RPG. O jogador escolhe uma entre 4 classes e atravessa 5 regiões enfrentando hordas de monstros até o coração da Fenda do Eclipse.

## Stack prevista

- **Engine:** Phaser 3 (HTML5 / WebGL, roda no navegador e como PWA)
- **Build:** Vite
- **Resolução base:** 480×270 px (escala inteira para 960×540 / 1920×1080), pixel art
- **Controles:** teclado, gamepad e toque (mobile)
